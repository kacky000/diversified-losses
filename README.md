# Diversified Losses

An entry for [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on make.fun.

`main.ts` writes one crypto joke to `/output/entry.txt`, about risk management done exactly to the letter.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
